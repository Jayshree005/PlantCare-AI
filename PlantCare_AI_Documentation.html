1. Executive Summary & Problem Solved

PlantCare AI is a full-stack automated agricultural diagnosis platform. It enables farmers, researchers, and home gardeners to diagnose plant pathological conditions instantly from leaf photographs, receive immediate organic and chemical care regimens, and observe real-time weather-induced disease spread risks.

💡 The Core Technical Innovation: Two-Stage Gatekeeper AI
Standard plant disease classification models fail catastrophically in real-world use because when a user submits a photo of a shoe, dog, or random houseplant, single-stage models force a false classification (e.g. 99% confident Aloe Rust). PlantCare AI solves this by deploying a Stage-1 Gatekeeper Validator Model that verifies leaf authenticity before invoking the Stage-2 MobileNetV2 Disease Classifier.

3. End-to-End System Pipeline

1

User Intake (upload.html)

The user selects a plant (Aloe Vera or Tomato) and drags-and-drops or uploads a leaf picture. Client-side validation checks image mime-type.

2

API Request & Preprocessing (backend/detection/views.py)

The image is streamed to POST /api/upload/. Pillow normalizes the color channels to RGB and resizes the tensor to (224, 224, 3).

3

Stage-1 Gatekeeper Validation

plant_validator_v3.keras (for Aloe) or tomato_validator.keras (for Tomato) verifies that the image is actually a leaf. If invalid, HTTP 400 is returned immediately.

4

Stage-2 MobileNetV2 Disease Classification

Valid leaf tensors are fed through the MobileNetV2 classifier. Softmax outputs are ranked to find the top predicted condition and confidence percentage.

5

Persistence & Care Plan Assembly

Django ORM stores the diagnosis in SQLite (PredictionHistory). Organic treatments, chemical remedies, and prevention tips are assembled into a JSON payload.

6

Live Meteorological Engine & Season Detection

On result.html, the user can enter their city. The backend geocodes coordinates via Open-Meteo, computes the current agricultural season (e.g. Sharad / Autumn), generates a 3-day forecast, and calculates rule-based disease risk scores.

5. Presentation & Interview Cheat Sheet

Q1: How would you summarize this project in 30 seconds?

"PlantCare AI is an intelligent agricultural health diagnostic platform. It uses a Two-Stage Gatekeeper Computer Vision pipeline with MobileNetV2 to first verify that an uploaded image is a real leaf, and then diagnoses specific diseases across Aloe Vera and Tomato plants. It combines this with live weather forecasting and seasonal intelligence to give farmers early warnings of fungal and bacterial disease outbreaks."

Q2: Why did you use MobileNetV2 instead of standard CNNs or ResNet?

MobileNetV2 employs depthwise separable convolutions that separate spatial filtering from feature combination. This reduced model size from 134 MB down to 9.7 MB (a 93% reduction) and cut CPU latency to ~35ms, allowing real-time edge or CPU cloud deployment without expensive GPUs.

Q3: How does the Two-Stage Gatekeeper architecture work?

Standard classifiers suffer from the "out-of-distribution" problem: uploading a picture of a car still outputs a plant disease with high confidence. We solve this by inserting a dedicated binary validator model that must confirm the image contains genuine leaf features before the disease classifier is ever invoked.

Q4: How does the system determine the agricultural season?

In views.py, determine_season() takes the user's city coordinates and country. For Indian/South Asian regions, it maps the current calendar to traditional agro-climatic seasons (Sharad, Varsha, Grishma, Shishir) and injects contextual plant care tips into the dashboard.

Q5: Is database storage persistent?

Yes. Prediction records and user accounts are persisted in SQLite (backend/db.sqlite3) through Django's ORM, complete with timestamps, foreign key associations, and hashed credentials.
